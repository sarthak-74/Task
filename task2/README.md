# Phishing Awareness Program

## Task 2 - Phishing Awareness Program

An interactive web-based cybersecurity awareness training module designed to educate users about phishing attacks and social engineering.

The application explains how to identify suspicious emails, fake login pages, fraudulent websites, and common social engineering techniques.

It also provides practical security recommendations, real-world case studies, and an interactive quiz to test the user's knowledge.

---

## Objectives

The main objectives of this project are:

- Explain what phishing is.
- Teach users how to identify suspicious emails.
- Explain how to recognize fake login pages.
- Explain how to identify fraudulent websites.
- Describe common social engineering techniques.
- Provide practical cybersecurity tips.
- Present real-world phishing-related case studies.
- Test user knowledge using an interactive quiz.
