# Secure Code Assessment

## Task 3 - Secure Code Assessment

This project demonstrates a security-focused source code review of a Python Flask application.

The assessment identifies common security vulnerabilities in a deliberately vulnerable application and provides a corrected implementation using secure coding practices.

---

## Objectives

- Examine application source code for security weaknesses.
- Perform manual security review.
- Use static code analysis.
- Identify common vulnerabilities.
- Assign severity levels.
- Recommend secure coding practices.
- Demonstrate fixes in a secure implementation.
- Document the assessment in a security report.

---

## Technologies Used

- Python 3
- Flask
- SQLite
- Werkzeug
- Bandit
